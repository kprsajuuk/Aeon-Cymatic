CentOS7遇到了两个问题
1，很多必要的组件都很老，比如python，CXXABI1.3.8 ,GLIBC,有些是因为编译需要。而且只能用node16
2，停止维护了，导致以前的很多yum install安装不了

具体问题主要是报CXXABI1.3.8找不到。之后把sqlite3换成better-sqlite3，但还是有python、GLIBC版本问题
然后从各处查到的方法，有的让yum install一些东西，发现源都被删了，官方库已经牵走了
比如执行如下命令：
# 安装 CentOS Software Collections (SCL)
sudo yum install centos-release-scl
# 安装较新版本的 GCC 和工具链
sudo yum install devtoolset-8 devtoolset-9 devtoolset-10
# 启用 devtoolset-9（推荐）
scl enable devtoolset-9 bash

这个按理说能解决不少问题，最后也确实成功了。但是一开始很长时间都是安装不上

一些执行方案参考链接
https://serverfault.com/questions/904304/could-not-resolve-host-mirrorlist-centos-org-centos-7

一些可能有帮助的命令
sed -i s/mirror.centos.org/vault.centos.org/g /etc/yum.repos.d/*.repo
sed -i s/^#.*baseurl=http/baseurl=http/g /etc/yum.repos.d/*.repo
sed -i s/^mirrorlist=http/#mirrorlist=http/g /etc/yum.repos.d/*.repo

sed -i 's/mirrorlist/#mirrorlist/g' /etc/yum.repos.d/CentOS-*
sed -i 's|#baseurl=http://mirror.centos.org|baseurl=http://vault.centos.org|g' /etc/yum.repos.d/CentOS-*

yum clean all

最后具体哪个命令成功的并不十分确定。但核心是把mirror.centos.org的库换掉
