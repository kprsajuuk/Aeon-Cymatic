# Aeon Cymatic

A unified, modular platform for experimental music tools and creative prototyping.

## Overview

Aeon Cymatic integrates multiple experimental music utilities into a single, cohesive environment designed for fast access to creative testing and prototyping tools. This platform addresses the common challenge in music production where various experimental utilities are scattered across different applications, providing a centralized solution that reduces coupling while improving maintainability.

## 🚀 Technology Stack
**Architecture:** Browser-Server (BS)
**Frontend:** Vite, TypeScript, React, Ant Design  
**Backend:** Node.js, SQLite  

## 🎵 Core Features

### Current Tools

1. **Visualizer**
   - Real-time audio visualization
   - Interactive visual feedback for audio signals

2. **Drum Beat**
   - Rhythm creation and experimentation
   - Pattern-based drum sequencing

3. **MIDI Notebook**
   - MIDI composition and notation
   - Musical idea organization and development
